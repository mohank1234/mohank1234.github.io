## About

A single-page, static portfolio built with plain HTML/CSS/JS — no build step, no framework, no dependencies. Deployed via GitHub Pages directly from this repo.

Covers: professional summary, skills & tools, experience timeline, featured projects (with links to source), achievements, and contact details.

## Structure

```
index.html            All markup, styles, and scripts (single file)
headshot.jpg           Profile photo
favicon.svg             Site favicon
og-preview.png          Open Graph / social share image
project-promtfoo.png    Screenshot used in the Projects section
Krishna_Mohan_B_Resume.pdf  Downloadable resume
robots.txt, sitemap.xml     SEO
```

## Running locally

No build tooling required — open `index.html` directly in a browser, or serve it:

```bash
npx serve .
```

## Deployment

Pushes to `main` publish automatically via GitHub Pages.
